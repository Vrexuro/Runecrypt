# M2.5 Isi Makam — Rencana Implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Arena 2D tidak lagi kosong. Ada kit makam (variasi lantai, dekorasi dinding, dekorasi lepas, debu, dan ambien) ditambah tiga benda yang bisa dimainkan: Anglo, Guci Abu, serta Nisan/Pilar/Sarkofagus.

**Architecture:**
- Logika murni (status Anglo, HP benda, undian jatuhan) ada di `Runecrypt.Core` dan diuji dengan EditMode test.
- Komponen MonoBehaviour di `Runecrypt.Game` memasang `IDamageable`, sehingga Bola Api dan Kobaran mengenainya tanpa perubahan kode senjata.
- Event statis `RoomEvents.Started` dipicu `ArenaDirector` setiap gelombang baru dimulai; aturannya satu gelombang = satu ruangan. Di M4, event yang sama dipicu saat pemain masuk ruangan.
- Sprite dibuat oleh satu script Python baru. Prefab dan penataan arena dikerjakan oleh builder editor baru yang dipanggil dari `Runecrypt/M1/Build All`.

**Tech Stack:** Unity 6000.3.26f1, URP 17.3 2D (Light2D, ShadowCaster2D), Tilemap + Tilemap Extras (`WeightedRandomTile`), Unity Test Framework, Python 3.12 + Pillow.

**Spec:** `Docs/specs/2026-11-24-isi-makam-design.md` (disetujui user 24 Nov 2026).

## Global Constraints
- Tidak ada paket atau asset pack baru. Tilemap Extras sudah terpasang.
- Semua sprite dibuat lewat script di `ArtSource/scripts/`, 16 PPU, 16x16 per tile, dengan palet GDD §7.1. PNG hasil generate tidak boleh diedit tangan.
- SFX dari sumber CC0, diolah lewat `make_sfx_cc0.py`, dan dicatat di GDD §14. **Minta izin user sebelum mengunduh apa pun.**
- Branch kerja: `feature/m2-5-isi-makam` dari `main`. Commit tanpa atribusi Claude. Jangan commit `ProjectSettings/VersionControlSettings.asset`.
- Nilai dari spec:
  - radius aturan cahaya Anglo **2,5**;
  - HP Guci **3**, peluang Bara Pemulih **0,15**;
  - Bara Pemulih memulihkan **1 HP** dan hilang setelah **10 detik**;
  - bobot lantai biasa sekitar **70%**;
  - jumlah benda di arena: **2 Anglo, 3 Guci, 2 Nisan, 1 Sarkofagus**, dan 2 pilar lama diganti sprite.
- Semua operasi Unity lewat skill `unity-mcp-skill`, pada instance proyek 2D `Runecrypt`. Setelah menulis script, tunggu kompilasi selesai lalu baca console.

## Review Focus
1. **Guci muncul lagi tepat di posisi pemain** saat gelombang baru. Pemain tidak boleh terjebak di dalam collider. Guci menunggu sampai area kosong. (Task 5, `AshUrn_RespawnWaitsUntilPlayerClear`)
2. **Tembakan pierce** yang mengenai Guci atau Anglo harus tetap terbang dan mengenai musuh di belakangnya. (Task 5, `PiercingShot_PassesUrnAndHitsEnemyBehind`)
3. **Kobaran mengenai beberapa benda sekaligus.** Semua guci dalam radius pecah dan Anglo dalam radius menyala. (Task 5, `BlazeRing_BreaksEveryUrnInRadius`)
4. **Musuh menyentuh Bara Pemulih.** Bara tidak boleh habis oleh musuh. (Task 5, `HealingEmber_IgnoresEnemies`)
5. **Benda menutupi titik spawn atau posisi awal pemain**, sehingga musuh muncul di dalam benda atau pemain langsung tersangkut. (Task 7, `CryptKit_KeepsSpawnsAndStartClear`)
