# M1.5 Juice dan Suara Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Setiap aksi di prototipe M1 punya umpan balik visual dan suara: kedipan, hit-stop, guncangan, knockback, angka damage, kematian "abu dan tulang", dan SFX CC0. Hasilnya dibandingkan dengan baseline M1 di uji seru.

**Architecture:**
- **Data.** Semua umpan balik dijelaskan oleh aset `FeedbackProfile` (ScriptableObject di Core), lalu diputar oleh satu `FeedbackPlayer` di scene.
- **Logika murni.** Hit-stop, guncangan, format angka, dan batas suara ditulis sebagai kelas murni di `Runecrypt.Core` dan diuji dengan EditMode test.
- **Rakitan.** Prefab, profil, dan wiring scene dirakit ulang oleh builder editor, sehingga `Runecrypt/M1/Build All` tetap mereproduksi scene.

**Tech Stack:**
- Unity 6000.3.26f1, URP 17.3 2D Renderer, Input System 1.20, Unity Test Framework 1.6.
- Python 3.12 dengan Pillow (sprite), serta numpy dan ffmpeg (potong SFX). Ketiganya hanya alat di ArtSource dan sudah terpasang di mesin user, bukan dependensi proyek.

**Spec:** `Docs/specs/2026-11-17-juice-design.md` (disetujui user 17 Nov 2026). Riset: `Docs/research/2026-11-17-game-feel.md`.

## Global Constraints

- Tidak ada paket Unity baru: tanpa Cinemachine, tanpa TextMeshPro, tanpa AudioMixer.
- SFX hanya dari 4 paket CC0 yang sudah diunduh: Fire Staff Collection (LEGIT Audio), Deep Bone Crack/Break SFX (Zane Little Music), Bones Rattle (congusbongus), Steam Release Sounds (bart). Kreditnya di GDD §14.
- File CC0 mentah disimpan di `ArtSource/cc0_raw/` dan di-ignore git. Yang di-commit hanya hasil potongan di `Assets/Runecrypt/Audio/`.
- Sprite baru dibuat lewat script Python di `ArtSource/scripts/`. PNG hasil generate tidak diedit dengan tangan. Ukuran pixel 16 PPU, mengikuti `PixelArtImporter`.
- Musuh dan efek baru cukup menunjuk aset `FeedbackProfile` atau prefab. Kode pemain dan musuh tidak berubah untuk konten baru.
- Anti-tujuan:
  - tanpa kedipan satu layar penuh;
  - tanpa guncangan untuk tembakan biasa (tembakan hanya mendapat sentakan 1 piksel);
  - FPS ≥ 60 di gelombang 4.
- Angka dari spec §5, salin persis:
  - Kedipan kena Tersingkap: alpha 1, 0,08 dtk. Kena gelap: alpha 0,35, 0,08 dtk.
  - Hit-stop: kena 0,03, mati 0,06, Uap 0,04, pemain kena 0,08 dtk.
  - Trauma: mati 0,25, Uap 0,3, pemain kena 0,45. Decay 1,5/dtk. Offset maksimum 3 piksel × trauma².
  - Knockback 4 tile/dtk dengan redaman 12/dtk, hanya untuk bola api.
  - Denyut cahaya tembakan: +30% intensitas selama 0,05 dtk.
  - Angka damage:
    - gerak: horizontal acak ±1 tile/dtk, naik 3 tile/dtk, gravitasi 9 tile/dtk², pudar setelah 0,6 dtk;
    - pool 40, skala 1 untuk normal dan 2 untuk besar;
    - pembulatan ke bilangan bulat terdekat, minimal 1.
  - Batas suara: 12 global, 4 per klip. Pitch ±5%.
  - Tumpukan abu maksimum 30. Serpihan tulang 6–8 dengan kecepatan 2–4 tile/dtk, berhenti dalam 0,3 dtk, diam 0,6 dtk lalu pudar. Kilatan mati: Light2D radius 1,5, intensitas turun dari 1 ke 0 dalam 0,15 dtk. Mata bertahan 0,3 dtk.
  - Pemain kena: kedipan merah 0,1 dtk, lalu berkedip alpha 0,4 ↔ 1 setiap 0,08 dtk selama 0,8 dtk.
- Branch kerja: `feature/m1-5-juice`, dibuat dari `feature/m1-prototipe` di checkout yang sama (CLAUDE.md). Merge ke `main` hanya dengan izin user.
