# M3a Musuh Baru dan Sisi Es: Rencana Implementasi

> **Untuk agen pelaksana:** WAJIB memakai sub-skill superpowers:subagent-driven-development atau superpowers:executing-plans (Native, seperti M2) untuk mengerjakan rencana ini task demi task. Setiap langkah memakai checkbox (`- [ ]`).

**Tujuan:** Dua musuh baru (Pelita Sesat dan Biarawan Beku), muatan elemen pada musuh, Kristal Es, susunan gelombang berdasarkan budget dengan batas 8 musuh, dan relic Mahkota Asap. Semuanya bisa dicoba di arena M2.

**Kenapa M3 dibagi dua** *(keputusan Claude)*: baris M3 di roadmap memuat 4 musuh, 3 benda reaksi, 1 reaksi baru, budget spawn, dan 2 relic. Itu terlalu besar untuk satu rencana yang dikerjakan satu orang. Pembagiannya:
- **M3a (rencana ini), sisi es:** arsitektur perilaku musuh, Pelita Sesat, Biarawan Beku, muatan elemen, Kristal Es, budget spawn, Mahkota Asap. Semuanya memakai reaksi Uap yang sudah ada.
- **M3b, sisi petir:** Ledakan Cahaya dan terang seruangan, Tiang Petir, Jubah Guntur, Gema Guntur, dan Mimik.

Setiap bagian bisa dimainkan sendiri.

**Arsitektur:**
- **`Enemy` tetap memegang semua yang sama untuk setiap musuh:** HP, aturan cahaya, Terbakar, Buta/Stun, knockback, damage sentuh, dan sekarang juga muatan elemen.
- **Cara bergerak dan menyerang pindah ke komponen otak** (`IEnemyBrain`) yang dipasang di prefab:
  - `ChaseBrain` untuk Tulang Penjaga, perilakunya sama dengan sekarang;
  - `SwoopBrain` untuk Pelita Sesat;
  - `RangedBrain` untuk Biarawan Beku.
- **Musuh baru cukup berupa data dan prefab:** sebuah `EnemyDefinition` ditambah otak yang dipilih. Kode `Enemy` tidak perlu diubah lagi (prinsip arsitektur di CLAUDE.md).
- **Logika murni di `Runecrypt.Core`**, diuji dengan EditMode test: siklus menukik, penjaga jarak, susunan gelombang dari budget, dan muatan elemen.

**Teknologi:** Unity 6000.3.26f1, URP 17.3 2D, Unity Test Framework (EditMode, ditambah test `EnterPlayMode` dengan pola `ProjectilePlayModeTests`), Python 3.12 dengan Pillow untuk sprite.

**Spec:**
- `Docs/GDD.md`: §5.1 (reaksi, muatan, benda reaksi), §5.2 relic 11, §5.4, §5.5 aturan 3, §6.1 (Pelita Sesat, Biarawan Beku), §6.2 (budget, batas 8).
- Roadmap: baris M3 di `Docs/plans/2026-11-17-roadmap.md`.

## Batasan Global
- **Tanpa paket baru dan tanpa asset pack.** Sprite dibuat lewat script di `ArtSource/scripts/`, dan PNG hasil generate tidak diedit dengan tangan.
- **Enum `Stat` hanya boleh ditambah di ujung.** `StatMod` menyimpan enum sebagai angka, jadi menyisipkan nilai di tengah akan merusak 10 aset relic yang sudah ada.
- **Angka GDD dipakai persis:**
  - Pelita Sesat: HP 6;
  - Biarawan Beku: HP 10, elemen Es, 3 serpih es, meninggalkan Genangan Beku saat mati;
  - muatan elemen kosong selama 4 detik setelah memicu reaksi;
  - Uap: radius 2,5 tile dan 3 detik;
  - Mahkota Asap: radius dan durasi Uap +50%;
  - paling banyak 8 musuh per ruangan;
  - musuh di gelap 20% lebih cepat (sudah berlaku lewat `Enemy`).
- **Angka yang tidak ada di GDD** ditetapkan Claude di task masing-masing, ditandai *(keputusan Claude, disetel saat playtest)*. Semuanya berupa field data, bukan konstanta di kode.
- **Reaksi tidak melukai pemain** (GDD §5.1).
- **Serpih es hanya melukai pemain.** Serpih menembus musuh lain dan hancur di dinding.
- **Test `EnterPlayMode` berjalan di dalam scene M1 yang terbuka.** Ikuti pola `ProjectilePlayModeTests`: `EnterPlayMode` di tingkat teratas method test, helper `Steps(n)`, dan objek test di x ≥ 100 (memori: unity-playmode-test-gotchas).
- Komentar dan teks UI ditulis dalam bahasa Indonesia, nama kode dalam bahasa Inggris.
- **Gerbang selesai:** semua EditMode test lulus, console bersih, scene dibangun ulang lewat `Runecrypt/M1/Build All`, dan user sudah mencoba di Play mode.

## Review Focus
1. **Reaksi di setiap tembakan.** Biarawan Beku yang ditembak terus-menerus hanya boleh memicu Uap sekali per 4 detik. Tembakan api selama muatan kosong tetap melukai seperti biasa (Task 2).
2. **Musuh buta atau stun tetap menyerang dari jauh.** Biarawan yang buta oleh Uap atau terkena stun tidak boleh menembak, dan Pelita yang buta tidak boleh menukik (Task 3, Task 4).
3. **Budget yang tidak habis dibagi.** Kalau sisa budget lebih kecil dari biaya musuh termurah, penyusunan gelombang harus berhenti, bukan berputar tanpa akhir. Hasilnya tidak boleh melebihi 8 musuh (Task 5).
4. **Musuh mati di frame yang sama dengan reaksinya.** Bola api yang membunuh Biarawan tetap memicu Uap kalau muatannya penuh, dan Genangan Beku yang dijatuhkan tidak langsung ikut meledak di frame itu (Task 2, Task 4).
5. **Serpih es dan tabrakan layer.** Saat ini `Projectiles` tidak bertabrakan dengan `Player`. Serpih es membutuhkan layer sendiri yang bertabrakan dengan Player dan Walls saja. Tanpa itu serpih menembus pemain, atau malah melukai musuh (Task 4).

**Siklus** *(durasi keputusan Claude, disetel saat playtest; semuanya field serializable)*:

2. Ancang-ancang selama 0,35 detik: diam, dan mata membesar sebagai telegraph. Arah tukikan dikunci ke posisi pemain saat fase ini dimulai.

**Antarmuka:**
```csharp
public enum SwoopPhase { Hover, Windup, Dive, Retreat }
public class SwoopCycle
{
    public SwoopCycle(float hover, float windup, float dive, float retreat, float diveSpeed, float retreatSpeed);

    public Vector2 Tick(float now, Vector2 toPlayer);
    public void Reset(float now); // dipanggil saat buta/stun: siklus mulai lagi dari Hover
}
```
